# SE4210_OverflowParable
This is a small interactive website that asks the user for different inputs, when the user overflows those inputs something on the webpage changes. This will help beginner programmers visualize the importance of input verification.

# How to run it
This is a simple 1 file html webpage that you simply need to opent the html file with a browser, whether that be integrated with the IDE, or simply opening the file with your browser of choice in file explorer.
IMPORTANT NOTE: This was designed and tested with Edge, there is no guarantee it will look good or function on another browser.
